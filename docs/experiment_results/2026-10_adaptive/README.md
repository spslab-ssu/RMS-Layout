# adaptive layout 실험 결과 전체 (2026-10-03 ~ 10-08)

모든 실험: Saffar multi_part 데이터(구성·생산율) 기반, z 모델, off(위치 고정) → joint(이동+재구성 허용, off 해로 warm start).
이득 = off − joint, %는 off 대비. **증명 범위** = [max(0, off bound − joint 해), off 해 − joint bound].
등급: **A 정확**(둘 다 최적) / **B 하한 증명**(off 최적 → 찾은 이득이 확실한 하한) / **C**(둘 다 미증명).
이동비는 따로 적지 않으면 0(이득의 상한).
